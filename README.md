# ChatGeo · ต้นแบบเว็บที่ใช้แผนที่จริง (OpenStreetMap)

ต้นแบบนี้รันได้ในเครื่องเลย ไม่ต้องลงโปรแกรมเพิ่มและไม่ต้องใช้ API key
แผนที่เป็น **OpenStreetMap ของจริง** (ผ่านบริการฟรี OpenFreeMap) ซูมลงไปได้ถึงระดับถนนและตึก

## ChatGeo มี 2 แบบ

| | หน้าเว็บในแอป Claude | ไฟล์ในเครื่อง (โฟลเดอร์นี้) |
|---|---|---|
| ข่าวสรุปเช้านี้ | **อัปเดตเองทุกเช้า 04:48 น.** และย้อนดูวันก่อนๆ ได้ | ข่าวชุดที่มากับไฟล์ (6 ต.ค. 2569) |
| แชท | **Claude ตอบจริง** จากข่าวของวันนั้น อ้างลิงก์ทุกครั้ง และสั่งแผนที่ได้ ใช้โควตา Claude ของคนที่เปิดดู | ตอบจากข่าวแบบสำเร็จรูป (ไม่มี AI) |
| แผนที่ | แผนที่โลกแบบออฟไลน์ (ซูมถึงถนนไม่ได้) | OpenStreetMap ซูมถึงระดับถนน |

ข่าวสรุปทุกเช้าทำโดยงานอัตโนมัติ "ChatGeo สรุปข่าวเช้า" ในบัญชี Claude ของคุณ (ดู/หยุดได้ที่เมนูงานตามกำหนดเวลาในแอป) ซึ่งจะค้นข่าวจริง ตรวจลิงก์ สรุปเป็นภาษาไทย ปักพิกัด แล้วบันทึกลงฐานข้อมูลของหน้าเว็บ
ไม่มีค่า API เพราะทั้งงานอัตโนมัติและแชทใช้แพ็กเกจ Claude ที่มีอยู่

## วิธีเปิด (ง่ายสุด)

1. แตกไฟล์ `chatgeo-prototype.zip`
2. ดับเบิลคลิก `index.html` แล้วเว็บจะเปิดใน Chrome หรือ Safari
3. ต้องต่ออินเทอร์เน็ตเพื่อโหลดแผนที่ OSM

> ถ้าไม่ได้ต่อเน็ต เว็บจะสลับไปใช้ **แผนที่สำรองแบบออฟไลน์** (Natural Earth) เองโดยอัตโนมัติ ยังลองทุกฟังก์ชันได้ แต่ซูมลงไปจะไม่เห็นถนน

### ถ้าดับเบิลคลิกแล้วแผนที่ไม่ขึ้น

บางเบราว์เซอร์ไม่ยอมให้เปิดไฟล์ตรงๆ ให้เปิดผ่านเซิร์ฟเวอร์เล็กๆ ในเครื่องแทน

1. เปิดแอป **Terminal** บน Mac
2. พิมพ์ `cd ` (มีเว้นวรรคหลัง cd) แล้วลากโฟลเดอร์ `chatgeo-prototype` มาวางใน Terminal จากนั้นกด Enter
3. พิมพ์ `python3 -m http.server 8000` แล้วกด Enter
4. เปิดเบราว์เซอร์ไปที่ http://localhost:8000
5. เลิกใช้เมื่อไรก็กด `Control + C` ใน Terminal

## ลองเล่นอะไรได้บ้าง

เว็บมี 2 หน้า สลับได้จากเมนูด้านบน

### หน้า "คุยกับโลก"

| ส่วน | วิธีใช้ |
|---|---|
| **แถบเลือกพื้นที่** (บนแผนที่) | กดที่ชื่อแต่ละชั้นเพื่อเลือกแบบเจาะลึก: ทวีป › ภูมิภาค › ประเทศ › ภาค › จังหวัด กด ✕ เพื่อกลับไปดูทั้งโลก |
| **ค้นหาพื้นที่** | กดปุ่ม "ค้นหา" หรือกดปุ่ม `/` บนคีย์บอร์ด แล้วพิมพ์ชื่อภาษาไทยหรืออังกฤษก็ได้ เช่น `เชียง` หรือ `japan` ใช้ลูกศรขึ้นลงแล้วกด Enter ถ้ายังไม่พิมพ์ จะมีพื้นที่ที่มีข่าวเช้านี้ให้เลือก |
| **แชท** | กดคำถามตัวอย่าง หรือพิมพ์ชื่อพื้นที่ เช่น "ภูเก็ตตอนนี้เป็นยังไง" แล้วแผนที่จะบินไปให้เอง คำที่ตอบได้ตอนนี้ ได้แก่ สรุป, อีสาน, น้ำมัน, AI และชื่อพื้นที่ทั้งหมด |
| **หมุดบนแผนที่** | กดหมุดเพื่อดูรายละเอียด แล้วกด "ถาม ChatGeo เรื่องนี้" |
| **ปุ่มหมวดข่าว** (มุมขวาบนของแผนที่) | เลือกว่าจะแสดงข่าวหมวดไหนบนแผนที่ และเปิดหรือปิดป้ายชื่อภาษาไทย |

### หน้า "สรุปเช้านี้"

| ส่วน | วิธีใช้ |
|---|---|
| **หัวข้อใหญ่** | บอกว่าเช้านี้มีกี่เรื่องในพื้นที่ที่เลือก |
| **ฟังสรุปเสียงภาษาไทย** | กดปุ่มเล่น เครื่องจะอ่านข่าวทีละเรื่อง และแผนที่จะบินไปที่เรื่องที่กำลังอ่าน (ใช้เสียงอ่านภาษาไทยของเครื่อง ถ้ายังไม่มี จะมีข้อความบอกวิธีเพิ่ม) |
| **แผนที่ + เลือกพื้นที่** | เลือกทวีป ประเทศ ภาค จังหวัด แล้วรายการข่าวด้านล่างจะเปลี่ยนตาม กดหมุดตัวเลขเพื่อดูหัวข้อข่าว |
| **แบ่งข่าว** | สลับ "ตามหมวด" (การเมือง เศรษฐกิจ ธุรกิจ เทคโนโลยี อากาศ สังคม) หรือ "ตามพื้นที่" (ไทย อาเซียน โลก) แล้วกดชิปเพื่อดูเฉพาะกลุ่มนั้น |
| **การ์ดข่าว** | กดหัวข้อหรือ "อ่านต่อที่ ..." เพื่อเปิดข่าวต้นฉบับ "ดูบนแผนที่" พาไปดูจุดนั้น ส่วน "ถาม ChatGeo" พาไปหน้าแชทพร้อมคำถาม |
| **ด้านขวา** | ตลาดปิดล่าสุด (กดแต่ละแถวเพื่อดูแหล่งข้อมูล) อากาศไทยวันนี้จากกรมอุตุฯ (กดภาคเพื่อไปดูบนแผนที่) และตั้งค่าช่องทางส่งสรุปทุกเช้า (ต้นแบบยังไม่ได้ส่งจริง) |

ทั้งสองหน้ามีปุ่ม **ลูกโลก** (สลับเป็นลูกโลก 3 มิติ) และ **☀ / ☾** (สลับธีมมืดหรือสว่าง) อยู่มุมขวาบน

### ทางลัดใน URL

- `index.html#cmi` เปิดหน้าแชทที่เชียงใหม่ทันที (ใช้รหัสพื้นที่ใน `data/data.js` เช่น `#th`, `#th-ne`, `#bkk`, `#pkt`)
- `index.html#brief` เปิดหน้าสรุปเช้านี้ และ `index.html#brief-th` เปิดสรุปของประเทศไทย
- `index.html?offline=1` บังคับใช้แผนที่สำรองแบบออฟไลน์
- `index.html?style=liberty` เปลี่ยนหน้าตาแผนที่ ใช้ได้กับ `liberty`, `bright`, `positron`, `dark`, `fiord`

## โครงสร้างไฟล์

```
chatgeo-prototype/
├── index.html        หน้าเว็บ
├── style.css         สีและเลย์เอาต์ (ธีมมืด/สว่าง, มือถือ)
├── app.js            การทำงานทั้งหมด: 2 หน้า แผนที่ แชท สรุป เสียงอ่าน เลือกพื้นที่
├── data/
│   ├── data.js       ข่าว 15 เรื่องพร้อมลิงก์ ตลาด อากาศ หัวข้อแชท พื้นที่ ป้ายชื่อไทย
│   ├── geo.js        แผนที่โลกสำรองแบบออฟไลน์ (Natural Earth)
│   └── countries.js  เส้นขอบประเทศที่ใช้ไฮไลต์ประเทศที่เลือก
└── vendor/           MapLibre GL JS 5.24.0 (ไลบรารีแผนที่ โอเพนซอร์ส)
```

อยากแก้ข่าวหรือเพิ่มพื้นที่ ให้แก้ที่ `data/data.js` ได้เลย ข่าวแต่ละเรื่องมี หัวข้อ สรุป ผลต่อไทย พิกัด แหล่งข่าว และลิงก์

## ขั้นต่อไปถ้าจะทำเป็นของจริง

1. **ดึงข่าวอัตโนมัติทุกเช้า**: ใช้ RSS ของสำนักข่าว หรือ GDELT แล้วให้ AI สรุปเป็นภาษาไทย อากาศจาก Open-Meteo หรือกรมอุตุฯ
2. **ต่อ AI จริง**: ส่งคำถามไปที่โมเดลภาษา พร้อมข้อมูลของพื้นที่ที่กำลังดู แล้วให้ตอบกลับเป็นข้อความพร้อมพิกัดหมุด
3. **ขอบเขตจังหวัดไทย**: เพิ่มไฟล์ขอบเขตจังหวัด เพื่อไฮไลต์ภาคและจังหวัดได้เหมือนระดับประเทศ
4. **เมื่อมีผู้ใช้เยอะ**: OpenFreeMap ใช้ฟรีและใช้เชิงพาณิชย์ได้ แต่ถ้าอยากควบคุมเองทั้งหมด ให้ตั้งเซิร์ฟเวอร์แผนที่ของตัวเอง
