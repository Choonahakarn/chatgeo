# ChatGeo · คุยกับโลกบนแผนที่

**เว็บจริง: https://choonahakarn.github.io/chatgeo/**

แผนที่เป็น **OpenStreetMap ของจริง** (ผ่านบริการฟรี OpenFreeMap) ซูมลงไปได้ถึงระดับถนนและตึก
ข่าวสรุปเช้าอัปเดตเองทุกวัน ไม่มีค่า API

## แผนที่ประเทศไทย

หน้าแรกเปิดที่ประเทศไทย แบ่งเป็น 6 ภาคตามราชบัณฑิตยสถาน (เหนือ อีสาน กลาง ตะวันออก ตะวันตก ใต้) กดภาคบนแผนที่เพื่อดูเฉพาะภาคนั้น
ปุ่ม **ชั้นข้อมูล** มุมขวาบนใช้เปิดหรือปิดข้อมูลสาธารณะเหล่านี้

| ชั้นข้อมูล | ที่มา | ความสด |
|---|---|---|
| ระดับน้ำในแม่น้ำ (สามเหลี่ยมสีตามระดับ: ล้นตลิ่ง น้ำมาก ปกติ น้อย น้อยวิกฤต) | คลังข้อมูลน้ำแห่งชาติ ThaiWater (สสน.) | ดึงสดทุกครั้งที่เปิดเว็บ |
| ฝนสะสม 24 ชม. (วงกลมสีฟ้า ยิ่งใหญ่ยิ่งตกหนัก) | ThaiWater (สสน.) | ดึงสดทุกครั้งที่เปิดเว็บ |
| พยากรณ์อากาศ 3 วัน ของเมืองหลักแต่ละภาค | Open-Meteo (CC BY 4.0) | ดึงสดทุกครั้งที่เปิดเว็บ |
| ภาพดาวเทียม | Sentinel-2 cloudless 2016 โดย EOX (CC BY 4.0) | ภาพพื้นหลังรายปี |

ถ้าดึงสดไม่ได้ เว็บจะใช้ข้อมูลสำรอง `data/live.json` ที่งานเช้าเก็บไว้แทน และบอกบนหน้าว่าเป็นข้อมูลสำรอง
ข้อมูลน้ำของ ThaiWater ใช้ API สาธารณะที่หน้าเว็บ thaiwater.net ใช้อยู่ ถ้าจะเปิดให้คนใช้จำนวนมาก ควรขอใช้ API อย่างเป็นทางการกับ สสน. ก่อน

## ข่าวเช้าขึ้นเว็บได้อย่างไร

เปรียบเหมือนโรงพิมพ์หนังสือพิมพ์ที่มีพนักงานกะเช้า

1. **ทุกเช้า** งานอัตโนมัติ "Chatgeo ข่าวเช้า" ที่ claude.ai/code/routines (ใช้แพ็กเกจ Claude ที่มีอยู่) ค้นข่าวจริง:
   - ข่าวไทยกระจาย 6 ภาค 10–12 เรื่อง
   - ข่าว AI ทั่วโลก ทั้งงานวิจัยและผลิตภัณฑ์ 5–6 เรื่อง
   - ข่าวต่างประเทศที่กระทบไทย 2–3 เรื่อง
2. งานนั้นเก็บข้อมูลน้ำ ฝน และพยากรณ์สำรองไว้ (`scripts/fetch_public_data.py`)
3. รัน `scripts/publish_brief.py` เพื่อตรวจข่าวอีกรอบ (ตัดลิงก์เสีย พิกัดผิด HTML แปลกปลอม) แล้วเขียน `data/latest.json` กับ `data/briefs/<วันที่>.json`
4. ส่งไฟล์เข้า GitHub (`main`) แล้ว GitHub Pages จะอัปเดตเว็บเองใน 1–2 นาที

คำสั่งทั้งหมดของงานนี้อยู่ใน [`ROUTINE.md`](ROUTINE.md) ส่วนงานในหน้า Routines ต้องตั้ง Network access เป็น **Full** เพื่อให้เปิดเว็บข่าวได้

## แชทบนเว็บ

ตอนนี้แชทตอบจากข่าวในสรุปเช้าของวันนั้น ยังไม่ใช้ AI จึงฟรีทั้งหมด
พิมพ์ได้ทั้งชื่อพื้นที่ (เชียงใหม่ ญี่ปุ่น อีสาน) หมวดข่าว (การเมือง เศรษฐกิจ อากาศ AI) หรือคำสำคัญในข่าว (IMF สตาร์บัคส์ ฮอร์มุซ)
แชทจะตอบพร้อมลิงก์ข่าวต้นฉบับ แล้วพาแผนที่ไปยังจุดนั้น ถ้าถามเรื่องที่ไม่มีในข่าววันนั้น จะบอกตรงๆ ว่าไม่มี

## แก้เว็บแล้วอัปโหลด

1. แก้ไฟล์ในโฟลเดอร์นี้ (หรือให้ Claude แก้ให้)
2. ดับเบิลคลิก `publish.command` ระบบจะดึงข่าวล่าสุดจาก GitHub ลงมาก่อน แล้วส่งไฟล์ที่แก้ขึ้นไป
3. รอ 1–2 นาที แล้วรีเฟรชเว็บ

> อย่าแก้ไฟล์ในโฟลเดอร์ `data/` เอง เพราะงานอัตโนมัติจะเขียนทับทุกเช้า

## เปิดในเครื่อง (ไม่ต้องต่อเน็ตก็ได้)

1. ดับเบิลคลิก `index.html` แล้วเว็บจะเปิดใน Chrome หรือ Safari
2. ถ้าไม่ได้ต่อเน็ต เว็บจะสลับไปใช้ **แผนที่สำรองแบบออฟไลน์** (Natural Earth) เอง ยังลองทุกฟังก์ชันได้ แต่ซูมลงไปจะไม่เห็นถนน
3. เปิดจากไฟล์ตรงๆ จะเห็นข่าวชุดที่มากับไฟล์ ถ้าอยากเห็นข่าวล่าสุดให้เปิดผ่านเซิร์ฟเวอร์ในเครื่อง:
   - เปิดแอป **Terminal** พิมพ์ `cd ` (มีเว้นวรรค) ลากโฟลเดอร์นี้มาวาง แล้วกด Enter
   - พิมพ์ `python3 -m http.server 8000` แล้วเปิด http://localhost:8000
   - เลิกใช้ให้กด `Control + C`

## ลองเล่นอะไรได้บ้าง

เว็บมี 2 หน้า สลับได้จากเมนูด้านบน

### หน้า "คุยกับโลก"

| ส่วน | วิธีใช้ |
|---|---|
| **แถบเลือกพื้นที่** (บนแผนที่) | กดที่ชื่อแต่ละชั้นเพื่อเลือกแบบเจาะลึก: ทวีป › ภูมิภาค › ประเทศ › ภาค › จังหวัด กด ✕ เพื่อกลับไปดูทั้งโลก |
| **ค้นหาพื้นที่** | กดปุ่ม "ค้นหา" หรือกดปุ่ม `/` บนคีย์บอร์ด แล้วพิมพ์ชื่อภาษาไทยหรืออังกฤษก็ได้ เช่น `เชียง` หรือ `japan` ใช้ลูกศรขึ้นลงแล้วกด Enter ถ้ายังไม่พิมพ์ จะมีพื้นที่ที่มีข่าวเช้านี้ให้เลือก |
| **แชท** | กดคำถามตัวอย่าง หรือพิมพ์ชื่อพื้นที่ หมวดข่าว หรือคำสำคัญ เช่น "ภูเก็ตตอนนี้เป็นยังไง" "ข่าวการเมือง" "IMF" แล้วแผนที่จะบินไปให้เอง |
| **หมุดบนแผนที่** | กดหมุดเพื่อดูรายละเอียด แล้วกด "ถาม ChatGeo เรื่องนี้" |
| **ปุ่มชั้นข้อมูล** (มุมขวาบนของแผนที่) | เลือกหมวดข่าวที่จะแสดง เปิดหรือปิดป้ายชื่อภาษาไทย และเปิดหรือปิดระดับน้ำ ฝน พยากรณ์ และภาพดาวเทียม |

### หน้า "สรุปเช้านี้"

| ส่วน | วิธีใช้ |
|---|---|
| **หัวข้อใหญ่** | บอกว่าเช้านี้มีกี่เรื่องในพื้นที่ที่เลือก |
| **ฟังสรุปเสียงภาษาไทย** | กดปุ่มเล่น เครื่องจะอ่านข่าวทีละเรื่อง และแผนที่จะบินไปที่เรื่องที่กำลังอ่าน (ใช้เสียงอ่านภาษาไทยของเครื่อง ถ้ายังไม่มี จะมีข้อความบอกวิธีเพิ่ม) |
| **แผนที่ + เลือกพื้นที่** | เลือกทวีป ประเทศ ภาค จังหวัด แล้วรายการข่าวด้านล่างจะเปลี่ยนตาม กดหมุดตัวเลขเพื่อดูหัวข้อข่าว |
| **แบ่งข่าว** | สลับ "ตามพื้นที่" (เหนือ อีสาน กลาง ตะวันออก ตะวันตก ใต้ AI โลก ต่างประเทศ) หรือ "ตามหมวด" (การเมือง เศรษฐกิจ ธุรกิจ เทคโนโลยี อากาศ สังคม) แล้วกดชิปเพื่อดูเฉพาะกลุ่มนั้น แผนที่จะซูมไปให้เห็นข่าวกลุ่มนั้นครบ |
| **การ์ดข่าว** | กดหัวข้อหรือ "อ่านต่อที่ ..." เพื่อเปิดข่าวต้นฉบับ "ดูบนแผนที่" พาไปดูจุดนั้น ส่วน "ถาม ChatGeo" พาไปหน้าแชทพร้อมคำถาม |
| **ด้านขวา** | น้ำและฝนตอนนี้ (ThaiWater) พยากรณ์รายภาค 3 วัน ตลาดปิดล่าสุด (กดแต่ละแถวเพื่อดูแหล่งข้อมูล) อากาศไทยวันนี้จากกรมอุตุฯ (กดภาคเพื่อไปดูบนแผนที่) และตั้งค่าช่องทางส่งสรุปทุกเช้า (ยังไม่ได้ส่งจริง) |
| **เลือกวันที่** | บนเว็บจริง กดวันที่ด้านบนเพื่อดูสรุปย้อนหลังได้ 30 วัน |

ทั้งสองหน้ามีปุ่ม **ลูกโลก** (สลับเป็นลูกโลก 3 มิติ) และ **☀ / ☾** (สลับธีมมืดหรือสว่าง) อยู่มุมขวาบน

### ทางลัดใน URL

- `index.html#cmi` เปิดหน้าแชทที่เชียงใหม่ทันที (ใช้รหัสพื้นที่ใน `data/data.js` เช่น `#th`, `#th-ne`, `#bkk`, `#pkt`)
- `index.html#brief` เปิดหน้าสรุปเช้านี้ และ `index.html#brief-th` เปิดสรุปของประเทศไทย
- `index.html?offline=1` บังคับใช้แผนที่สำรองแบบออฟไลน์
- `index.html?style=liberty` เปลี่ยนหน้าตาแผนที่ ใช้ได้กับ `liberty`, `bright`, `positron`, `dark`, `fiord`

## โครงสร้างไฟล์

```
chatgeo-prototype/
├── index.html            หน้าเว็บ
├── style.css             สีและเลย์เอาต์ (ธีมมืด/สว่าง, มือถือ)
├── app.js                การทำงานทั้งหมด: 2 หน้า แผนที่ แชท สรุป เสียงอ่าน เลือกพื้นที่
├── data/
│   ├── latest.json       ข่าวเช้าล่าสุด (งานอัตโนมัติเขียนทุกเช้า)
│   ├── briefs/           ข่าวเช้าย้อนหลัง 30 วัน วันละไฟล์
│   ├── live.json         ข้อมูลน้ำ ฝน พยากรณ์สำรอง (งานเช้าเขียน)
│   ├── th-regions.js     ขอบเขต 6 ภาคและเส้นแบ่งจังหวัดของไทย (Natural Earth)
│   ├── data.js           พื้นที่ ป้ายชื่อไทย หมวดข่าว และข่าวชุดสำรอง
│   ├── geo.js            แผนที่โลกสำรองแบบออฟไลน์ (Natural Earth)
│   └── countries.js      เส้นขอบประเทศที่ใช้ไฮไลต์ประเทศที่เลือก
├── scripts/
│   ├── publish_brief.py  ตรวจข่าวแล้วเขียนลง data/ (งานอัตโนมัติเรียกใช้)
│   └── fetch_public_data.py  เก็บข้อมูลน้ำ ฝน พยากรณ์สำรองลง data/live.json
├── ROUTINE.md            คำสั่งของงานสรุปข่าวเช้า
├── publish.command       ดับเบิลคลิกเพื่ออัปโหลดขึ้น GitHub (อยู่ในเครื่องเท่านั้น)
└── vendor/               MapLibre GL JS 5.24.0 (ไลบรารีแผนที่ โอเพนซอร์ส)
```

อยากเพิ่มพื้นที่หรือป้ายชื่อ ให้แก้ที่ `data/data.js` ส่วนข่าวรายวันมาจาก `data/latest.json`

## ขั้นต่อไป

1. **AI ในแชทบนเว็บ**: ต่อโมเดลภาษาผ่านเซิร์ฟเวอร์เล็กๆ (เช่น Cloudflare Workers) เพื่อซ่อน API key ไม่ให้คนอื่นเห็น
2. **เฝ้าพื้นที่ + แจ้งเตือน LINE**: ให้ผู้ใช้เลือกพื้นที่ที่สนใจ แล้วส่งสรุปเข้า LINE ทุกเช้า
3. **ขอบเขตจังหวัดไทย**: เพิ่มไฟล์ขอบเขตจังหวัด เพื่อไฮไลต์ภาคและจังหวัดได้เหมือนระดับประเทศ
4. **โดเมนของตัวเอง**: ตั้งค่า Custom domain ในหน้า GitHub Pages
